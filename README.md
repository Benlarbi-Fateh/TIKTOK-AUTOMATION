# TikTok Content Automation MVP

Projet d'automatisation locale de création de contenu TikTok.

## Technologies

- Python
- SQLite
- n8n
- Ollama
- Edge-TTS
- Telegram
- FFmpeg

## Optional extras

Some media features are optional and require extra packages. Install extras with:

```bash
pip install -r requirements-extra.txt
```

This will install optional packages like `edge-tts`, `Pillow`, and `ffmpeg-python` used by media generation and rendering.
